## ⚙️ Как это работает

Макрос использует триггер **Shake Device** в MacroDroid и пользовательские сцены.

1. 🤳 Встряхни устройство, находясь на домашнем экране.
2. 📋 Выбери нужную контактную информацию.
3. 📱 MacroDroid откроет полноэкранное окно с QR-кодом.
4. 🔍 Отсканируй QR-код другим устройством.
5. 💾 Созданный QR-код сохраняется локально для быстрого доступа.

Для телефонного контакта макрос создаёт QR-код `vCard 3.0`, содержащий имя, номер телефона, email, организацию и должность.

## 🔧 Настройки

При первом запуске открывается интерфейс настройки контактной информации.

### 📌 Контактная информация

| Поле                    | Описание                                                                            |
|-------------------------|-------------------------------------------------------------------------------------|
| `phone`                 | Номер телефона и данные контакта для vCard                                          |
| `fullname`              | Имя контакта                                                                        |
| `email`                 | Email                                                                               |
| `organization_name`     | Название организации/компании                                                       |
| `organization_position` | Должность                                                                           |
| `website`               | Имя пользователя или адрес сайта                                                    |
| Социальные сервисы      | Имя пользователя, номер телефона или идентификатор профиля в зависимости от сервиса |

Для каждого сервиса используется собственный флаг `active` и значение. В меню выбора отображаются только включённые сервисы.

### 📌 Хранение QR-кодов

| Переменная   | Описание                            | По умолчанию          |
|--------------|-------------------------------------|-----------------------|
| `rootPathQR` | Корневой путь для хранения QR-кодов | `/sdcard/MacroDroid/` |
| `dirQR`      | Папка для QR-кодов                  | `ShakeContacts`       |

QR-коды сохраняются в:

`/sdcard/MacroDroid/ShakeContacts/`

В папке также создаётся файл `.nomedia`, чтобы изображения QR-кодов не отображались в галерее.

## 🌐 Использование

### 🤳 Открытие меню

Встряхни устройство, когда на экране открыт домашний экран Android.

Макрос покажет список включённых контактных сервисов.

### 📱 Отображение QR-кода

Нажми на нужный сервис.

Макрос покажет:

- изображение QR-кода;
- закодированное значение;
- кнопку `OK` для закрытия окна.

### ⚙️ Изменение контактных данных

Открой настройки из меню выбора контакта и измени необходимые данные или список включённых сервисов.

## 🌍 Языки

Макрос автоматически определяет язык устройства и использует соответствующий перевод интерфейса, если он доступен.

Английский используется как резервный язык.

---

## 🔐 Конфиденциальность

- 📱 Контактные данные обрабатываются локально в MacroDroid.
- 💾 QR-коды сохраняются локально на устройстве.
- 🌐 После настройки подключение к Интернету не требуется.
- 📤 Макрос не отправляет контактные данные на удалённый сервер.

---

## ⚠️ Ограничения

- Поведение при сканировании QR-кода зависит от приложения-сканера на принимающем устройстве.
- Обнаружение встряхивания зависит от датчика движения устройства и особенностей Android.
- Макрос рассчитан на запуск с домашнего экрана Android.
- В зависимости от версии Android может потребоваться разрешение на доступ к хранилищу.
- QR-коды создаются и сохраняются на устройстве в виде PNG-файлов.
